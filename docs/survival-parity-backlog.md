## Notes

- Textures are generated procedurally on a canvas from a name to colour table in
  `src/textures.js`, so a new colour variant needs no art asset, only a palette entry.
- Materials already ship `vertexColors: true` and the mesher already emits per-vertex colour
  for biome tinting, so a per-block colour tint needs no new pipeline.
- The game currently has 6 of 16 wool colours and 9 of 12 plank types, so several families
  are cheaper to finish than to start.
